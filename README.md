# Cirrova

Public pages for the Cirrova weather app, served by GitHub Pages: the privacy policy
(`privacy/`), support contact, and the warning-area outlines the app derives from OpenStreetMap
(`osm-areas/`, ODbL, built by `tools/outlines` in the app repository). The policy is written in
the app repository (`docs/privacy-policy.md`) and copied here as HTML.
